## Restore drill (must pass before any invitation)
1. Create a few synthetic entries, a group with a percentage split and a settlement, using a `*@example.com` account.
2. Record from the live DB:
   - revision
   - table list
   - row counts per table
   - `sum(amount_paise)` by direction for posted entries
   - each account's derived balance
   - group net per member
   - `count(audit_events)`
3. In the panel, use **Restore from backup / fork** to a **new cluster** (never onto the live one), at a point in time after step 1.
4. Run the same queries on the restored cluster. Every number must match.
5. Record the result and the time taken (that's the RTO) in `DISASTER_RECOVERY_PLAN.md`, then delete the temporary cluster.

**Local equivalent:** `scripts/windows/restore.ps1` restores a dump into a new database, refuses the live database and existing names, verifies the SHA-256, and prints the same comparison. It hasn't been run yet, because Docker is unavailable while C: is full.
